# Porcelain Atlas V1 → V2 refinement record

V1 remains unchanged at `porcelain-atlas.html`. V2 is a separate Phase 0A visual study and is not imported by the production application.

## System changes

- Replaced the muted rust accent with a two-orange system: vivid `#F15A2A` with deep-ink text for the primary action and identity, plus measured `#C74616` for the rarer white-text dark-orange treatment.
- Rebuilt the layout around an explicit 4 px spacing scale, a stable reading measure, aligned editorial sections, and intentional wide-block exceptions.
- Replaced the hero/card balance with one continuous paper canvas, a compact course atlas, and a small lesson-route index.
- Introduced restrained radius, shadow, and hairline hierarchies rather than applying the same rounded bordered surface everywhere.
- Changed display typography from a generic Georgia treatment to an Iowan/Palatino editorial stack with an Apple-system interface stack.

## Learning and media changes

- Replaced the concentric-circle placeholder with an original four-route vector: reading lines, listening waveform, writing mark, and conversation geometry connect to one evidence centre.
- Rebuilt the media block as a contained pale-cobalt field with balanced illustration, metadata, duration, transcript action, caption, and reading flow.
- Converted the four-skill content from a small card grid into an indexed editorial list with distinct skill glyphs.
- Refined the exam tip into a soft orange field where the bright brand colour is an annotation rather than a large fill.
- Reworked the PDF resource into a compact document row with hierarchy, privacy context, preview action, and representative page state.

## Assessment and control changes

- Replaced browser-default-looking radios, selects, and text inputs with styled native controls, measured 46–48 px heights, consistent focus rings, and compact internal geometry.
- Rebuilt inline completion as phrase-aware flex content. At compact widths each gap becomes a labelled full-width row, avoiding punctuation collisions and broken sentence baselines.
- Reduced primary-action visual weight through compact geometry, careful label/icon spacing, restrained shadow, and a contrast-tested vivid orange with deep-ink text. The darker orange remains available for the rarer white-text treatment.
- Replaced question cards with a continuous assessment sequence separated by rhythm and hairlines.
- Added explicit correct, incorrect, partial, pending, disabled, loading, empty, error, and unavailable treatments using icon and text as well as colour.
- Preserved the prototype boundary: feedback states are pre-authored visual reveals; no answer inspection, scoring, authentication, or persistence was added.

## Responsive and motion changes

- Desktop uses a course rail, editorial paper, and on-page index; tablet removes only the secondary page index; mobile becomes a purpose-built single stream with a course-map dialog.
- Added compact 320 px rules for headings, sections, actions, feedback, and completion controls rather than proportionally shrinking desktop geometry.
- Motion is limited to control response, progress entry, disclosure geometry, and loading detail. Manual and system reduced-motion modes reduce durations to effectively zero.
